# Traceback Hackathon Documentation

Project scope and planning for an AML SaaS data investigation and resolution proof of concept. The documentation follows three pillars: Web App and Observable ETL, Domain Knowledge and Retrieval, and Graph-Based Investigator.

## Read on GitHub

Start with the [documentation home](outputs/project-docs/README.md), then follow the linked scope, architecture, pillar details, and shared contracts. Markdown is the editable source; adjacent HTML pages provide the offline reading interface.

## Read on your laptop

Clone this public repository with Git; no GitHub sign-in is required:

```sh
git clone https://github.com/chapmandaniel/traceback-hackathon-docs.git
```

Open `outputs/project-docs/index.html` from the cloned folder in a browser. Search, navigation, and diagrams work offline without installing dependencies.

Alternatively, download [the documentation ZIP](outputs/traceback-project-docs.zip), extract it, and open `project-docs/index.html`. Keep the entire extracted folder together.

## Update the documentation

Edit Markdown under `outputs/project-docs/`, then regenerate the HTML and search index using the [build instructions](outputs/project-docs/site-tools/README.txt). In this checkout, run those instructions from `outputs/`, the directory containing `project-docs/`.

Commit source and regenerated files together. Refresh `outputs/traceback-project-docs.zip` when updating the downloadable edition.

This repository contains planning documents and their HTML reader. POC implementation and production readiness remain unverified.
